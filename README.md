Pixel Pantry · Minecraft Bedrock 食物資源包產生器
把自訂食物快速打包成可直接匯入的 Bedrock 資源包 + 行為包（.mcaddon）。

功能
自訂食物名稱、ID、飽食度、飽和度
支援食用後狀態效果（速度、再生、抗火…）
上傳 PNG 圖示（建議 16×16 / 32×32 / 64×64）
一鍵產生 .mcaddon 或原始 JSON 檔案包

使用方式
直接開啟 minecraft-food-pack-generator (4).html
填寫左側表單並上傳 PNG
點「產生並匯入基岩版套件」下載 .mcaddon
雙擊 .mcaddon 即可匯入 Minecraft Bedrock

注意
僅支援 Minecraft Bedrock Edition
產生的 BP 使用 function + tick 方式套用效果（不依賴 Script API）
PNG 不會上傳到任何伺服器
